## 1. 引言

### 1.1 目的

本文档定义个人导航网站的全部功能与非功能需求，作为实施的唯一依据（spec 先行，防止过度工程）。

### 1.2 范围

开发一个纯前端个人导航页，包含：大图标首页、分类标签页、自定义背景（毛玻璃质感）、搜索框、响应式布局与暗色模式。数据以 YAML 文件维护，通过 `git push` 更新。

### 1.3 定义与缩写

| 术语 | 含义 |
|------|------|
| pinned 网站 | YAML 中标记 `pinned: true` 的网站，显示于首页大图标区 |
| 降级链 | favicon 获取失败时按优先级回退的加载策略 |
| 字母坞 | 图标加载全部失败时的兜底：网站名首字母彩色方块 |

### 1.4 读者与维护

个人项目，作者即唯一用户与维护者。需求变更直接修改本文档并注明版本。

## 2. 总体描述

### 2.1 产品定位

单用户、单设备为主的个人浏览器起始页/导航页。更新频率低，观感优先，维护摩擦可接受（改 YAML + push）。

### 2.2 技术约束（硬性）

- **纯静态前端**：HTML + CSS + 原生 JavaScript，无框架、无构建步骤。
- **零 CDN 依赖**：js-yaml 以 `js-yaml.min.js` 文件形式下载到仓库本地引用。
- **无后端、无数据库、无 API key**：不使用任何需要密钥的外部服务。
- **部署**：GitHub Pages 直接发布仓库根目录（或 `/docs`），push 即生效。

### 2.3 运行环境

- 现代桌面浏览器（Chrome/Edge/Firefox 近两个大版本）为主，移动端浏览器可用。
- 访问者网络环境为中国大陆（影响 favicon 源选型，见 FR-4）。

### 2.4 假设与依赖

- js-yaml v4.x 本地文件可用且兼容目标浏览器。
- 任何第三方 favicon 服务（含国内聚合源）在中国大陆网络下均可能不可达，故字母坞兜底必须"可控且必好看"——它是唯一由本项目完全掌控的视觉元素；外部源只是提高真实图标命中率的"尽力而为"层级。
- `backdrop-filter` 在目标浏览器可用；不支持时降级为半透明纯色卡片（优雅降级，不算缺陷）。

## 3. 功能需求

### FR-1 数据层：YAML 单一数据源

- FR-1.1 全部导航数据与站点配置存于 `data/sites.yml`，前端通过 `fetch` + js-yaml 在运行时解析。
- FR-1.2 首页大图标区与分类标签页**共享同一份数据**：首页 = 各分类中 `pinned: true` 网站的合集，不单独维护列表。
- FR-1.3 YAML 加载或解析失败时，页面显示可读的错误提示（含错误行信息），不白屏。
- FR-1.4 数据更新方式仅为：编辑 YAML → commit → push。不提供页面内编辑。

**YAML Schema（规范，实现必须兼容）：**

```yaml
settings:
  title: 我的导航                    # 页面标题
  background: assets/bg/dusk.svg    # 默认背景图（仓库相对路径）
  bgBlur: true                      # 背景图模糊开关

searchEngines:                      # 搜索框引擎列表，首个为默认
  - { name: Google, url: "https://www.google.com/search?q=%s" }
  - { name: 百度,   url: "https://www.baidu.com/s?wd=%s" }
  - { name: Bing,   url: "https://www.bing.com/search?q=%s" }

backgrounds:                        # 页面切换器列出的候选背景
  - assets/bg/dusk.svg

categories:
  - name: 常用工具                  # 分类名，即标签页名
    sites:
      - name: GitHub                # 网站名（用于字母坞与 alt）
        url: https://github.com
        pinned: true                # 可选，true 则出现在首页大图标区
        desc: 可选的文字解释，悬停卡片以 tooltip 展示
```

- `pinned` 缺省视为 `false`。
- `%s` 为搜索词占位符。

### FR-2 首页大图标区

- FR-2.1 首页默认视图：搜索框（FR-6）+ pinned 网站大图标网格。
- FR-2.2 大图标尺寸 ≥ 64px，卡片带悬停反馈，点击新标签页打开。
- FR-2.3 pinned 网站按 YAML 中分类顺序、分类内顺序排列。

### FR-3 分类标签页

- FR-3.1 顶部标签栏列出 YAML 中全部分类 + "首页"。
- FR-3.2 切换标签页无刷新切换内容区；当前标签高亮。
- FR-3.3 分类内网站以较小卡片网格展示（图标 + 名称）。
- FR-3.4 标签栏随模型构建一次后复用：切换标签**只更新当前项状态**（`aria-current`），不得每次切换清空并重建整条标签栏（会连带重建全部监听器）。重复点击当前标签不得触发内容区整体重建。当前项状态用 `aria-current` 表达而非 `aria-selected`（按钮未声明 `role="tab"`，后者属无效 ARIA）。

### FR-4 图标降级链

按以下优先级加载，任一失败自动进入下一级，全程不阻塞渲染：

1. **国内可达的 favicon 聚合源（可配置，默认 `https://api.iowen.cn/favicon/{domain}.ico`）**：规避 Google `s2/favicons` 在中国大陆经常不可达的问题，返回较清晰的图标。源地址为单一常量（`js/icons.js` 的 `FAVICON_PRIMARY`），换源只改一处；备选含 `ico.fun`、`favicon.im`（SVG 矢量）、`icon.horse` 等，均无 API key。
2. `<origin>/favicon.ico`：站点自有图标，作为第二外部尝试。
3. 字母坞：网站名首字符 + 由域名哈希决定的稳定渐变底色方块，并在 64px 大图标（pinned）上附加域名小字，保证兜底视觉精致。

- FR-4.1 加载走浏览器 HTTP 缓存（`<img>` 标签），同设备不重复请求。
- FR-4.2 每级监听 `onerror` 触发回退；三级全失败时保证字母坞必然渲染。
- FR-4.3 指向第三方聚合源的图标请求必须设 `referrerpolicy="no-referrer"`（不向外部泄露本站地址，见 NFR-4），并设 `decoding="async"` 使解码不阻塞主线程。首屏（pinned）图标用 `loading="eager"`，分类内小图标用 `loading="lazy"`。

### FR-5 背景与毛玻璃

- FR-5.1 背景图资源存于仓库 `assets/bg/` 目录，候选清单来自 `backgrounds`。
- FR-5.2 生效背景 = localStorage 中用户选择 → 缺省回落到 `settings.background`。
- FR-5.3 背景选择在设置页完成（见 FR-10）。
- FR-5.4 背景模糊开关（`bgBlur`）：默认取 `settings.bgBlur`，用户可在设置页覆盖并持久化。
- FR-5.5 导航卡片统一 `backdrop-filter` 半透明毛玻璃质感；不支持时降级半透明纯色。
- FR-5.6 背景路径来自 YAML，写入 CSS `url()` 前必须转义 `"` 与 `\`：既防止路径内容突破 `url()` 注入样式，也保证含空格的路径仍能正常渲染，不得直接字符串拼接。
- FR-5.7 `backdrop-filter` 只允许存在于卡片、标签、搜索框、遮罩这几层视觉主体上；**不得**在浮窗面板与站点 tooltip 这类已处于模糊祖先内部、且自身底色接近不透明（约 ≥90% alpha）的元素上再叠一层——嵌套模糊根会重复采样并额外占用 GPU 纹理，视觉收益接近零。v1.2 追加：整体背景模糊开启（`body.bg-blur`）时，上述各层的背景**已经是模糊图**，必须跳过元素级 `backdrop-filter`——对模糊结果再采样纯耗 GPU 而视觉无收益。

### FR-6 搜索框

- FR-6.1 首页顶部居中搜索框，引擎可从 `searchEngines` 列表切换，记住上次选择（localStorage）。
- FR-6.2 输入后 Enter 跳转 `url` 中**所有** `%s` 替换为 `encodeURIComponent(关键词)` 后的地址，新标签页打开。注意 `String.prototype.replace` 只替换首个匹配，多占位符 URL 会残留字面量 `%s`，故实现须按全部占位符替换（如 `split('%s').join(...)`）。

### FR-7 响应式

- FR-7.1 CSS Grid 自适应列数：桌面 6–8 列，平板 4 列，手机 2–3 列。
- FR-7.2 分类标签在宽度压缩时自动换行显示，不使用水平滚动条。滚轮切分类已于 v1.2 移除（需 `passive:false` 阻塞滚动且触控板几乎无法触发）。

### FR-8 主题（明暗）

- FR-8.1 主题三选一：跟随系统（`prefers-color-scheme`）/ 浅色 / 深色，默认跟随系统。
- FR-8.2 用户在设置页切换，选择存 localStorage，优先级高于系统设置；系统主题变化时"跟随系统"模式实时响应。
- FR-8.3 暗色下毛玻璃卡片、文字对比度保持可读（WCAG AA 级别主观可读即可）。
- FR-8.4 主题必须在首屏绘制前生效：`<head>` 内联同步脚本读单键设置 `nav.settings` 的 `theme`（缺省按系统 `prefers-color-scheme` 解析）写上 `html[data-theme]`，不得等 YAML 请求解析完成——否则深色用户每次进页闪白。内联脚本与 `js/prefs.js` 的键名/结构是同一契约，改一处必须改两处。

### FR-9 （v1.2 废止）插件挂载点

v1.1 曾为"零插件"预留 `#plugin-slot` 容器与注册约定注释。实现中该挂载点从未被任何代码或插件使用，规范与实现已互相矛盾（smoke test 反向断言其不存在），属死代码，v1.2 起从规范与实现双双移除。真实插件需求出现时，另立 FR 重新讨论机制。

### FR-10 设置页（统一收口所有设置）

- FR-10.1 左上角齿轮按钮（`#settings-toggle`）为设置唯一入口，点击弹出浮窗（模态）。
- FR-10.2 浮窗包含：背景选择（缩略图网格）、背景模糊开关、主题（跟随系统/浅色/深色）。后续新设置项一律加在此处，不再散落在页面上。
- FR-10.3 **草稿模式**：打开时拷贝当前生效设置进草稿，浮窗内改动只改草稿，不立即影响页面。
- FR-10.4 关闭浮窗时应用配置并持久化。关闭途径：× 按钮 / "应用并关闭" / 点击遮罩 / Esc。
- FR-10.5 设置优先级：localStorage 覆盖 > YAML 默认值。若用户选择与默认一致，则不写入 localStorage（避免 YAML 改动被旧偏好盖住）。v1.2 起全部设置合并为**单键 `nav.settings`**（JSON 对象，含 `background`/`bgBlur`/`theme`/`engine`），只存显式覆盖的字段，无覆盖时整个键删除；旧多键方案（`nav.background` 等四键 + ''/'1'/'0' 三态编码）废弃。
- FR-10.6 浮窗须为**真模态**：声明了 `aria-modal="true"` 就必须真的把焦点关在里面。打开时焦点移入浮窗；`Tab` / `Shift+Tab` 在浮窗内首尾循环、不得逸出到被遮住的页面元素；关闭时焦点交还齿轮按钮。声明了模态语义却不实现焦点约束，属实现缺陷而非"够用即可"。
- FR-10.7 四种关闭途径（× / 应用并关闭 / 点遮罩 / Esc）语义一致：均应用草稿并持久化。本期不提供"放弃改动"路径；若日后新增取消按钮，须显式定义其丢弃草稿的语义，不得沿用现有四条路径。

## 4. 非功能需求

| 编号 | 类别 | 要求 |
|------|------|------|
| NFR-1 | 性能 | 首屏仅请求 HTML/CSS/JS/YAML + pinned 图标；无骨架阻塞，总请求数与 pinned 数量线性相关。脚本统一 `defer`，让浏览器先完成解析与首屏绘制。切换标签不得重建标签栏或重复触发内容区渲染（见 FR-3.4）。 |
| NFR-2 | 可靠性 | 任一外部资源（favicon 服务）失败不影响页面主体渲染 |
| NFR-3 | 可维护性 | 新增/删除网站只改 YAML；新增背景只传图 + 改 YAML 清单 |
| NFR-4 | 安全 | 仓库不含任何密钥/token；不发起携带凭据的跨域请求；向第三方图标源请求时不发送 Referer（`referrerpolicy="no-referrer"`），不泄露本站地址。站点与引擎链接只放行 `http/https`。 |
| NFR-5 | 体积 | js-yaml 本地文件 + 全部自有资源合计 < 300KB（不含背景图）。v1.1 实测约 120KB。仓库内不得保留未被 `index.html` 引用的图标文件——未被引用的资源既不生效，又撑大部署体积。 |
| NFR-6 | 兼容 | `backdrop-filter`、Grid、`fetch` 缺失时优雅降级，不报错白屏。`transition` 等简写中使用较新语法（如 `display .15s allow-discrete`）时，必须先声明一条不含新语法的基础过渡、再用增强声明覆盖；否则旧浏览器会把整条简写判为非法值，连带丢失 opacity/transform 等全部过渡。 |
| NFR-7 | 可访问性 | 自定义控件（标签、齿轮、搜索按钮、背景缩略图、主题分段项、应用按钮、站点卡片）必须提供可见的 `:focus-visible` 焦点环，否则键盘用户会「丢失焦点」。不得用 `aria-live` 包裹每次切换都会整体重建的内容区（会导致整屏朗读）；切换状态由标签的 `aria-current` 表达。深色模式须通过 `color-scheme` 让原生控件（下拉框、滚动条）一并切换。 |
| NFR-8 | 资源开销 | 不得为大面积重复元素（如数十张卡片）添加 `will-change` 提层——那会把优化目标从省内存反转为吃显存。模糊与提层的使用范围以 FR-5.7 为准。 |

## 5. 文件结构约定

```
/
├── index.html              # 唯一页面；结构与首屏主题内联脚本
├── README.md               # 使用说明（非需求）
├── css/style.css           # 全部样式；改观感只动这里
├── js/
│   ├── vendor/js-yaml.min.js   # YAML 解析，本地引入不走 CDN
│   ├── icons.js            # 图标降级链 + 字母坞（纯函数，无 DOM）
│   ├── data.js             # 数据层：YAML → 归一化模型（无 DOM）
│   ├── prefs.js            # localStorage 读写（无 DOM）
│   ├── ui.js               # UI 层：模型 → DOM，交互经 handlers 上报
│   └── app.js              # 组合根：接线 + 持久化
├── data/sites.yml          # 唯一数据源
├── assets/
│   ├── bg/                 # 背景图
│   └── icon/               # favicon / apple-touch-icon，须全部被 index.html 引用
└── docs/SRS.md
```

分层硬约束（与实现一一对应）：`data.js` / `icons.js` / `prefs.js` 不得触碰 DOM；`ui.js` 不得 `fetch`、不得读 localStorage、不得解析 YAML；`app.js` 不承载业务逻辑。层间契约 = **归一化模型结构 + CSS 类名**（`.site-card` / `.site-card--pinned` / `.site-icon` / `.site-tile` / `.site-name` / `.tab[aria-current]` / `.bg-thumb[aria-current]` / `.seg-item`），重写 UI 只动 `ui.js` + `style.css`。

## 6. 明确不做（Out of Scope）

1. 任何真实插件（天气、股票等）——v1.2 起连空挂载点也不再保留（见废止的 FR-9）。
2. 页面内编辑导航数据、GitHub API 直写、localStorage 数据覆盖层。
3. 后端、代理、构建步骤、前端框架。
4. 多用户、多设备同步（localStorage 类设置换设备失效，属可接受行为）。
5. UI 文案多语言。
6. **PWA 化**：webmanifest、Service Worker、离线缓存、`android-chrome-*` 安装图标。本站无安装与离线诉求，为几张图标补一套 manifest 属过度设计；对应图标不纳入仓库（见 §8）。
7. **卡片网格的跨标签缓存 / DOM 复用**：站点规模在数十级，图标重复请求已由浏览器 HTTP 缓存覆盖；为切换标签缓存各标签网格节点只会让常驻 DOM 与内存单调上升，与本项目的省内存目标相悖。

## 7. 验收标准

勾选状态反映 v1.1 代码走查当次的实测结果（`[x]` = 已实测通过，`[ ]` = 尚未实测）。

- [x] 打开页面即显示搜索框 + pinned 大图标，无白屏、无控制台报错。
- [ ] 修改 YAML 中某网站 `pinned` 后 push，首页与分类页同步变化。
- [x] favicon 服务不可达时，依次回退到 `<origin>/favicon.ico` 与字母坞，不影响主体渲染。
- [ ] 齿轮 → 设置页：换背景、切模糊、切主题，关闭后生效并持久化；刷新保持；清除 localStorage 后回落 YAML 默认。
- [x] 浮窗内改动在关闭前不影响页面（草稿模式）；Esc 关闭生效且 `aria-expanded` 复位。
- [ ] × / "应用并关闭" / 点遮罩 三种关闭途径逐一实测（本期与 Esc 共用同一关闭路径，v1.1 仅实测 Esc）。
- [ ] 手机宽度（375px）下布局不破。**标签栏为自动换行，不做横向滚动**（FR-7.2；v1.0 此条误写为"可横滑"，与 FR-7.2 自相矛盾，v1.1 订正）。走查中在约 639px 宽下观察到标签栏换行正常，但 375px 未专门实测，故不勾选。
- [x] 系统暗色下首次打开即为暗色。
- [ ] YAML 语法错误时页面显示错误信息而非白屏。

## 8. 决策溯源

### 8.1 grill-me 评审结论（v1.0）

| 决策点 | 结论 | 否决项及原因 |
|--------|------|--------------|
| 数据更新 | 改 YAML + git push | 页面内编辑/API 直写：开发量大、token 泄露风险 |
| 插件 | 本期 YAGNI，仅轻量挂载点 | 完整插件机制：零插件下属过度设计 |
| YAML 消费 | js-yaml 本地引入 | 构建期转 JSON / Jekyll：违背零构建约束 |
| 图标源 | 国内聚合源 → 站点源 → 精致字母坞 | Google s2 在中国大陆常不可达；纯站点源 16px 放大糊；字母坞是唯一可控视觉，故做成渐变 + 域名小字兜底 |
| 背景 | 仓库 assets + 设置页选择存 localStorage | 页面上传：复杂度与收益不匹配 |
| 设置入口 | 统一设置页（齿轮+浮窗，草稿模式，关闭时应用） | 顶栏分散按钮：设置项增多后不可维护 |

### 8.2 代码走查结论（v1.1）

| 决策点 | 结论 | 否决项及原因 |
|--------|------|--------------|
| 标签栏渲染 | 构建一次后只同步 `aria-current` | 每次切换重建：连带丢弃并重建全部监听器，纯浪费 |
| 重复点击当前标签 | 直接返回，不重渲染内容区 | 原实现会重建整块网格并重新解码全部图标 |
| `backdrop-filter` 取舍 | 保留于卡片 / 标签 / 搜索框 / 遮罩；移除浮窗面板与 tooltip 上的嵌套层 | 嵌套模糊根重复采样，且这两处底色本就接近不透明，移除后视觉几乎无损 |
| 是否加 `will-change` | **不加** | 数十张卡片各自提层会显著推高显存，与省内存目标相反 |
| `#grid` 的 `aria-live` | 移除 | 内容区每次切换整体重建，会导致整屏朗读；切换状态已由 `.tab[aria-current]` 表达 |
| 模态浮窗 | 补焦点约束 | 既已声明 `aria-modal="true"`，不约束焦点等于给了错误的语义承诺 |
| 未引用图标 | 删除 `android-chrome-*` 与调试截图，把 16/32/48 小图改为真正引用 | 项目无 manifest 需求；未引用资源不生效却撑大体积，实测自有资源由约 370KB 降至约 120KB，使 NFR-5 重新达标 |
| 网格缓存 | 不做跨标签 DOM 复用 | 站点量级小、HTTP 缓存已够；缓存只增常驻内存 |

### 8.3 代码走查结论（v1.2）

| 决策点 | 结论 | 否决项及原因 |
|--------|------|--------------|
| 元素级 `backdrop-filter` | `body.bg-blur` 开启时关闭卡片/标签/齿轮/搜索框的模糊 | 背景已是模糊图，逐元素再采样纯耗 GPU，视觉无收益（FR-5.7 追加） |
| 主题应用时机 | 提前到 `<head>` 内联同步脚本，先于首屏绘制 | 原实现等 fetch+解析 YAML，深色用户每次进页闪白（新增 FR-8.4） |
| 设置存储 | 四键合并为单键 `nav.settings` JSON，只存覆盖字段 | 多键 + 三态（''/'1'/'0'）编码的合并逻辑易错；同时修复 theme 与"一致不写"契约不符的问题 |
| 插件挂载点 | 规范与实现双双移除（废止 FR-9） | 为不存在的插件预留的空容器是死代码，规范与实现已自相矛盾 |
| 编辑器预览反向同步 | 移除；预览只读、表单为唯一事实源 | 双向解析回环是全项目最复杂机制；且聚焦跳写导致保存可能取到陈旧文本。头部注释块改为导出时拼回 |
| 滚轮切标签 | 移除 | `passive:false` 阻塞滚动 + 抖动阈值，触控板几乎触发不了，小众交互不值 8 行 |
| `#bg-layer` 过渡 | 删除 `background-image` 过渡声明 | 该属性不可过渡，属死代码 |
| 未引用 favicon 尺寸 | 删除 16/48 PNG，index.html 同步删 link | NFR-5 既定"仓库内资源须全部被引用" |
| 图标 `decoding="async"` | 补上 | FR-4.3 早已要求，实现漏了——规范与实现漂移的实例 |
